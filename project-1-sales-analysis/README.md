# Project 1: Sales Data Analysis

## Overview

This project analyzes sales data to identify trends, top-performing
products, customer behavior, and regional performance.

## Tools

- SQL
- Python
- Pandas
- Power BI
- Excel
- GitHub

## Business Questions

1. What are the total sales and profit?
2. Which products generate the highest sales?
3. Which regions perform best?
4. How do sales change over time?
5. Which customers generate the most revenue?
6. Which products or regions need improvement?

## Project Workflow

1. Data cleaning
2. Exploratory data analysis
3. SQL analysis
4. Python analysis
5. Power BI dashboard
6. Business recommendations
