# Online Retail Sales & Customer Analysis

## Overview

This project analyzes over one million online retail transactions from a UK-based retailer to identify sales trends, product performance, customer purchasing behavior, and geographic patterns.

The project demonstrates an end-to-end data analytics workflow using SQL, Python, Pandas, and Power BI.

## Dataset

**Source:** UCI Machine Learning Repository – Online Retail II

The dataset contains transactions from December 2009 through December 2011.

Key fields include:

* Invoice
* StockCode
* Description
* Quantity
* InvoiceDate
* Price
* Customer ID
* Country

## Business Questions

1. What is the total sales revenue?
2. Which products generate the highest revenue?
3. Which countries perform best?
4. How does revenue change over time?
5. Which customers generate the most revenue?
6. Which products have weak sales performance?
7. What is the cancellation/return rate?
8. How many customers are repeat customers?

## Data Preparation

The analysis will include:

* Identifying missing values
* Checking duplicate records
* Validating data types
* Identifying cancelled transactions
* Checking unusual quantities and prices
* Creating calculated revenue
* Preparing the data for analysis and visualization

### Revenue Calculation

Revenue will be calculated as:

**Revenue = Quantity × Price**

The dataset does not contain product cost information. Therefore, actual profit and profit margin will not be calculated.
